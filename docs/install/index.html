ติดตั้งโปรแกรม ระบบยา รพ.สวี

หน้าต่างแคบด้านขวาของจอ อยู่บนสุดเสมอ · มีไอคอนบนหน้าจอ
⬇ ดาวน์โหลดชุดติดตั้ง
ติดตั้ง
  1. แตกไฟล์ SaweeRx.zip (คลิกขวา → Extract All)
  2. ดับเบิลคลิก install.bat — รอสักครู่ ระบบติดตั้งให้เอง
  3. เปิดจากไอคอน ระบบยา รพ.สวี บนหน้าจอ
ถอนการติดตั้ง
  1. ดับเบิลคลิก uninstall.bat ในโฟลเดอร์เดิม
ถ้าเปิดไม่ได้ กรุณาแจ้งห้องยา
